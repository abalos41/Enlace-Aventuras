# Enlace-Aventuras

**Enlace-Aventuras** es un videojuego desarrollado en JavaScript utilizando [**Quintus**](http://www.html5quintus.com/). 

El proyecto comenzó como un trabajo de final de ciclo. Finalmente, surgió la oportunidad de trabajar en otro proyecto más complejo y divertido, así que decidí centrarme en él y dejar este en segundo plano. Aun así, quería terminar al menos el primer personaje, por lo que el juego se quedó en su primer nivel.

![CPIFP](https://docenzia.com/docs/87537/00238bfd00cf81356800a199e417ac31)

## Personajes

**Manuel**

El objetivo de Manuel es llegar al final del mapa para conseguir su sueldo.
